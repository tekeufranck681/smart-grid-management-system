Q1. Which layer(s) does this event touch?

Answer

State layer only

Reasoning

ISLANDING separates a portion of the grid logically (micro-grid).

Topology structure remains unchanged.

Only the state of affected nodes and edges (island membership, operational control) changes.

🔒 Locked

Q2. What is the minimal direct mutation caused by this event?

Answer

Assign affected nodes and edges to a new island ID in the state snapshot

Reasoning

The event declares that a micro-grid is now electrically separated.

No other values (generation, demand, flows) are changed directly.

🔒 Locked

Q3. What invariants must remain true immediately after this mutation?

Answer

Each node and edge belongs to exactly one island at a time

Node and edge identities are unchanged

Topology remains consistent

Island assignment is valid (no node in multiple islands)

Reasoning

Domain and simulation integrity must be preserved.

State must reflect the new isolation correctly before any simulation.

🔒 Locked

Q4. What consequences must be derived from this mutation?

Answer

Recompute power balance per island

Detect potential overloads or deficits in the separated island

Identify flows that are now isolated from main grid

Trigger potential load shedding or generation adjustments for the island

Update violations or alerts for island-specific conditions

Reasoning

Effects are simulation consequences of the new island, not event intent.

🔒 Locked

Q5. What structural or topological queries are required?

Answer

Which nodes belong to the newly created island?

Which edges are internal vs external to the island?

Which generation sources can supply the island?

Which loads are affected by island separation?

Reasoning

Needed to compute consequences accurately.

Topology is queried but not modified.

🔒 Locked

Q6. What prioritization, ordering, or selection rules are required?

Answer

Load priority for potential shedding within the island

Generation dispatch within island (renewables vs thermal priority)

Edge reconnection order if island is reintegrated (future event)

Reasoning

Islanding may require prioritization to maintain stability.

Critical nodes and loads must be protected first.

🔒 Locked

Q7. Which data structures are therefore required?

Answer

Graph → for reachability and flow paths inside the island

Union-Find → optional, for quick detection of isolated components

Priority Queue → for load shedding / generation adjustments

Reasoning

Efficient querying of nodes, edges, and island membership is necessary.

Flow redistribution and prioritization require these structures.

🔒 Locked

Q8. What is the termination condition for processing this event?

Answer

Processing stops when:

Island membership is fully assigned AND

Consequences (power balance, flows) are stabilized OR

No further corrective actions can be applied within the island

Reasoning

Ensures deterministic completion.

Prevents infinite adjustments or repeated state changes.

🔒 Locked

Q9. What outputs must be produced and stored?

Answer

New state snapshot with island assignments

List of islands (IDs and member nodes/edges)

Load shedding applied (if any)

Flow adjustments and voltage changes

Violations or alerts per island

Event reference

Reasoning

Required for replay, rollback, and post-simulation analysis.

Critical for metrics on micro-grid operation.

🔒 Locked
