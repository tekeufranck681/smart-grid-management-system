Sequence Steps – Password Reset (Combined)

Actors / Components:

User (requests reset and sets new password)

Web App / CLI

AuthService

EmailService

PasswordService (hashing/verification)

Database (User + PasswordResetToken + RefreshToken tables)

Flow:

Request Password Reset (Forgot Password)

User submits email

AuthService creates PasswordResetToken

EmailService sends email with link

Resend Password Reset Email (optional)

If token expired or user requests again

AuthService generates new token

EmailService sends email

Reset Password

User clicks link and submits new password

AuthService validates token

PasswordService hashes new password

Update User.password_hash

Token marked used

All refresh tokens revoked
